# landing

## Purpose

Public home page.

## Variants

- Top nav; hero with announcement chip, d1 title, lead, Connect Gmail (lg) and secondary CTA, product frame with the real app; channel strip; How it works (four pipeline tiers); In every ticket (bento); Earned trust (dark band); Why Kairo; Your data; final CTA; footer.

## States

- **default**: As described in Variants.
- **hover**: Not applicable.
- **active**: Not applicable.
- **disabled**: Not applicable.
- **loading**: Not applicable.
- **error**: Not applicable.

## Accessibility

- One h1; sections with headings in order; product frame described with `aria-label`.

## Domain value

Read-only by default; first value in 60 seconds; the human stays at the center.

## Platforms

- **web**: Public web (no session).
- **desktop**: Not part of the desktop app design.
- **mobile**: Designed. Below 720px the page margin is 16px, grids collapse to one column and hide-sm elements are hidden.
