# auth-error

## Purpose

Authentication error.

## Variants

- Status panel, error variant: access denied, link expired, domain not allowed, unknown; each with its title, description and primary action.

## States

- **default**: Access denied.
- **hover**: Not applicable.
- **active**: Not applicable.
- **disabled**: Not applicable.
- **loading**: Not applicable.
- **error**: This screen is an error state.

## Accessibility

- See status-panel.

## Domain value

Recovers the user from a failed sign-in.

## Platforms

- **web**: Public web (no session).
- **desktop**: Not part of the desktop app design.
- **mobile**: Designed. Below 720px the page margin is 16px, grids collapse to one column and hide-sm elements are hidden.
