# pricing-table

## Purpose

Plan comparison table.

## Variants

- Table with sticky header, group rows in the `label` style, feature column at 32% in `text.secondary`, mono values, — when not included, ok check when included. Recommended column on `accent.soft`.

## States

- **default**: As described in Variants.
- **hover**: Not applicable.
- **active**: Not applicable.
- **disabled**: Not applicable.
- **loading**: Not applicable.
- **error**: Not applicable.

## Accessibility

- Real `<table>` with `scope`; the first header cell has a screen-reader label.

## Domain value

Compares tickets per month, pipeline tiers, replies, team and access, support and compliance.

## Platforms

- **web**: Public web (no session).
- **desktop**: Not part of the desktop app design.
- **mobile**: Designed. The table scrolls horizontally inside its container (min 760px).
