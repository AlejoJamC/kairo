# faq

## Purpose

Frequently asked questions.

## Variants

- Native `<details>`: 60px summary at 15.5px/500 with a plus icon; answer 14.5/1.65 `text.secondary`; dividers above each item and below the last.

## States

- **default**: Closed.
- **hover**: The plus icon turns `text.primary` and the summary shows a pointer cursor.
- **active**: Open: plus rotates 45° (150ms).
- **disabled**: Not applicable.
- **loading**: Not applicable.
- **error**: Not applicable.

## Accessibility

- Native disclosure; no script required.

## Domain value

Billing and product questions on the pricing page.

## Platforms

- **web**: Public web (no session).
- **desktop**: Not part of the desktop app design.
- **mobile**: Designed. Below 720px the page margin is 16px, grids collapse to one column and hide-sm elements are hidden.
