# shortcuts-dialog

## Purpose

Replaced by command-palette in its Commands scope. Not used on any screen.

## Variants

- ⌘/ (also ⌘?, and ? outside text fields), "All commands" in account-menu, Help › All commands in app-menu and "⌘/ all commands" in status-bar open command-palette in the Commands scope, which lists every command with its keys.
- The official set of shortcuts lives in command-palette.

## States

- **default**: Not applicable: the dialog is not shown.
- **hover**: Not applicable.
- **active**: Not applicable.
- **disabled**: Not applicable.
- **loading**: Not applicable.
- **error**: Not applicable.

## Accessibility

- See command-palette (Commands scope).

## Domain value

None: the complete command list is in command-palette.

- **desktop**: Not used; see command-palette.
- **mobile**: Not designed.
