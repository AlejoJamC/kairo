# feature-card

## Purpose

Content card on the public web.

## Variants

- Bento: h3 title, small text and one real app piece (evidence panel, signals, source list, note card, keyboard keys or draft card); spans 2, 4 or 6 columns.
- Pipeline tier: tier dot and label, title, text, footer with a metric and a mono value; min height 236px.
- Benefit: 34px icon box, title, text.

## States

- **default**: As described in Variants.
- **hover**: Not applicable.
- **active**: Not applicable.
- **disabled**: Not applicable.
- **loading**: Not applicable.
- **error**: Not applicable.

## Accessibility

- Headings in order inside each section.

## Domain value

Explains triage tiers, accountability of AI decisions, signals, internal notes, keyboard work and drafts.

## Platforms

- **web**: Public web (no session).
- **desktop**: Not part of the desktop app design.
- **mobile**: Designed. Below 720px the page margin is 16px, grids collapse to one column and hide-sm elements are hidden.
